NDI Aurora ROS 2 package

This ROS 2 package will connect the Aurora NDI system to the ROS2 network and will publish the orientation (in quaternions) and position (in mm) data for later data manipulation. This README file will guide you in installing this package on your system. This package will only work on a Ubuntu 22.04 machine and if you have installed ROS 2 Humble in your system.

It will be advised to go through the ROS 2 Humble tutorials before continuing.

Installation

To install this project, follow these steps:

  1. Download the sensors_experiment folder from Microsoft Teams
  2. Unzip the downloaded folder and place the sensors_experiment folder into your system's home directory. Once downloaded, the sensors_experiment folder should have the following directory structure:
  3. Before compiling your ROS 2 node, it is important to compile the NDI Aurora API functions located in the aurora_api folder as the ROS 2 package depends on these functions to connect the Aurora system to the network and retrieve data. To do that, follow these steps:
    1. Access the aurora_api folder by writting the following command in a new terminal: 
      cd sensors_experiment/aurora_api
    2. Clean the API with make clean 
      make clean
    3. Compile the API with make 
      make
    4. Once the NDI Aurora API is built, go back to the root file of your project 
      cd ..
  4. Build the ROS 2 package by running the rebuild_ws.sh file in the same terminal. 
    ./rebuild_ws.sh
    If the terminal returns the error: bash: ./rebuild_ws.sh: Permission denied, you will need to make the rebuild_ws.sh script executable on your system before running the previous command. For that, write the following command in the terminal: 
    chmod +x rebuild_ws.sh
  5. If you do not see any errors, the NDI Aurora ROS 2 node was successfully installed on your system.

Usage

To run the NDI Aurora ROS 2 node, please follow these steps:

  1. In a new terminal, source your ROS 2 workspace setup files: 
    cd sensors_experiment/
    source install/setup.bash
  2. Run the NDI Aurora ROS 2 node: 
    ros2 run aurora_ndi_pkg aurora_talker
If you want to see the orientation (in quaternion) and position (in mm) data retrieved from the sensor, please follow these steps:
  1. In a new terminal, source your ROS 2 workspace setup files: 
    cd sensors_experiment/
    source install/setup.bash
  2. The sensor data is published on the ROS 2 network using the /aurora_transform topic. To visualise its content, write the following command: 
    ros2 topic echo /aurora_transform
